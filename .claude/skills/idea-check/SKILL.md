# Idea check

The founder wants every idea cross-referenced before build mode. Someone else may
already do it, which is fine: what matters is whether we can execute it better and
whether it moves the business. Run this check, give the verdict, and only build
after the founder says go.

## 1. Say the idea in one sentence

Who it's for, what they do with it, and why it's better than what they use today.
If you can't write that sentence, the idea isn't ready.

## 2. Look for who already does it

Search the web (current results, not memory) for:
- Direct competitors: apps or sites doing the same thing.
- Near competitors: big platforms that could add it (YouTube, TikTok, Apple News,
  Google News, Snapchat).
- Failures: who tried and stopped, and why (for example Artifact, 2024).

Note what each one does well and where they fall short.

## 3. Check the evidence

- **Demand:** surveys or usage data that show people want this (Reuters Institute
  Digital News Report, Pew Research, app-store rankings, funding news).
- **Fit:** does it serve our edge, which is stories connected into chains you can
  follow (money, people, place) from the headline down to the roots?
- **Money:** which revenue line does it help? Schools, subscriptions, sponsorship
  or licensing. If none, say so.

## 4. Check the risks

- **Rules:** YouTube API terms (no selling ads on embedded YouTube content),
  copyright and footage rights, privacy (COPPA and FERPA for anyone under 18 or
  in schools), app-store rules.
- **Cost:** build time for a solo founder, and running cost per month.
- **Trust:** could it spread misinformation, mislabel footage, or push outrage?
- **Minors:** engagement features stay off by default on teen and school accounts.

## 5. Give the verdict

Use this format, and keep it short:

| | |
|---|---|
| Idea | one sentence |
| Who else does it | names, with links |
| Evidence for | one to three points, with links |
| Risks | one to three points |
| Revenue line | schools / subscription / sponsorship / licensing / none |
| Cost | build time and monthly cost, rough |
| Verdict | **Build**, **Test first** (and the cheapest test), or **Park** |

Cite every outside fact with a link. Say plainly when something couldn't be
verified. Never invent numbers.

## 6. Keep a record

Add one line per checked idea to `deeper-news/idea-log.md`: date, idea, verdict,
and the main reason, so past decisions can be revisited when facts change.
